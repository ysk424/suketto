# 助人（すけっと）

Blender の N パネルで Codex と会話する、個人用の日本語拡張機能です。
OpenAI の Codex CLI 本体を使い、質問、シーンの確認、モデル生成、ファイル編集、ターミナル操作を同じ会話から行います。

## 使う環境

- Windows x64 / Blender 5.2 以降
- Codex CLI（検証済み: 0.155.1）
- Codex を利用できる ChatGPT のサブスクリプション

API キーは不要です。既存の Codex CLI の ChatGPT ログインを利用します。
未ログインなら、助人の「ChatGPT でログイン」からブラウザーでログインします。
モデルの利用可否と使用枠はログインしたアカウントに従います。
認証情報は Codex 自身が管理し、助人はトークンを読み取り・複製・保存しません。

## インストール

開発用は、このリポジトリで `./install.ps1` を実行します。
Blender 5.2 のユーザー拡張機能フォルダーから、このリポジトリへのリンクを作成します。
その後、Blender の「編集 → プリファレンス → アドオン」で「助人」を有効にしてください。
すでに Blender が起動している場合は一覧を更新するか、作品を保存してから再起動してください。

配布用 ZIP は `tools/package.py` を Python 3.11 以降で実行して作成します。
生成された `dist/suketto-0.1.1.zip` を「ディスクからインストール」で読み込めます。

## チャット

3D ビューで `N` → **助人** → **Codex に接続**。
プリセットは次の3つです。

| 用途 | モデル | 推論量（effort） |
| --- | --- | --- |
| 問い合わせ | GPT-5.6 Terra | 中（medium） |
| 通常の Blender 操作 | GPT-6 Astra | 中（medium） |
| 難しい仕事 | GPT-6 Astra | 非常に高い（xhigh） |

モデルと推論量は個別にも変更できます。利用可能なモデルと推論量は Codex から取得します。
プリセットは同じ会話のまま切り替えられ、次の送信に適用されます。

- 入力欄は3行です。日本語 IME で入力でき、3行を改行でつないで一つのメッセージとして送ります。
- 「長文入力」は8行の入力ダイアログです。任意の長さの文章は「貼り付け」で下書きにできます。
- 「送信」で会話し、応答中には「追加指示を送る」「応答を停止」を使えます。
- チャット欄は初版の約3倍（24行）の高さで、スクロールできます。過去の発言を読むときは「最新の発言を追う」をオフにします。
- 「会話履歴 → 開く」で前の会話を再開できます。「コピー」は作業ログも含む会話全体をコピーします。
- 「設定」で作業フォルダー、Codex 実行ファイル、PC・シーンの操作許可を指定できます。変更は切断・再接続で反映します。

通常の Codex の設定、認証、ターミナルツールを使用します。
PC・シーンの操作許可は、この個人用構成では初期状態でオンです。
オフでは Codex の読み取り専用設定を使用し、Blender の Python 操作ツールを提供しません。
Codex の管理ポリシーや既存設定によって、操作が拒否されたり追加の確認が表示される場合があります。

## Blender の直接操作

MCP サーバーは不要です。助人が Codex に次の内部ツールを提供します。

- `blender_scene`: 現在のシーン、選択、オブジェクトの情報を取得
- `blender_python`: 開いている Blender のメインスレッドで Python を実行
- `blender_screenshot`: Blender ウィンドウの画像を取得して Codex に返す

生成物は現在のシーンに直接現れます。通常のシーン変更は Blender の Undo 対象です。
ファイル書き込み、外部コマンド、環境設定変更などは Blender の Undo では戻せません。
Python 実行中は Blender のメインスレッドを使用します。長い処理そのものは「停止」で即座に中断できないため、Codex には短い処理へ分けるよう指示しています。
画面画像はモデルが必要と判断してツールを呼んだ場合に送信します。

## 保存先

会話表示用の履歴は Blender のユーザー設定フォルダー内 `suketto/conversations/` に保存します。
Codex 本来の会話履歴も通常の Codex の保存先に残ります。
会話を続ける際は Codex の `thread/resume` を使用します。
`.blend` に認証情報や会話履歴を埋め込みません。

## 実装と検証

Codex App Server と標準入出力の JSON-RPC で接続します。
UI・会話状態は Blender のメインスレッド、通信の読み取りのみバックグラウンドスレッドです。
通信イベントから直接、バックグラウンドで `bpy` を操作しません。
動的ツールのインターフェースは Codex の実験的 API のため、CLI 更新時に互換性確認が必要です。

- `tests/blender_smoke.py`: プリセット、effort の送信、シーン操作、停止後の操作拒否、履歴を検証
- `tests/live_chat.py`: 実際のサブスク接続で Terra の質問、Astra の生成、モデル切替・会話再開を検証。実行すると利用枠を消費します

検証例:

```powershell
$blender = Join-Path $env:LOCALAPPDATA 'Programs\Blender Foundation\Blender 5.2\blender.exe'
& $blender -b --factory-startup --python-exit-code 1 --python tests/blender_smoke.py
```

公式仕様: [Codex App Server](https://learn.chatgpt.com/docs/app-server)、[Codex のモデル](https://learn.chatgpt.com/docs/models)。
